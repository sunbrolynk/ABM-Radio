# Licences I accept

Only these go on air. The licence that counts is the one on the source page when I download the
file, and every approved item has evidence of it in `evidence/`.

| Licence | ID in `tracks.csv` | Notes |
|---|---|---|
| [Public domain](https://creativecommons.org/publicdomain/mark/1.0/) | `PD` | Public domain in the USA at minimum. |
| [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) | `CC0-1.0` | |
| [CC BY](https://creativecommons.org/licenses/by/4.0/) 2.0 to 4.0 | `CC-BY-4.0` etc. | The attribution line is shown publicly. |
| [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/) 2.0 to 4.0 | `CC-BY-SA-4.0` etc. | As CC BY. |
| [CC BY-ND](https://creativecommons.org/licenses/by-nd/4.0/) 2.0 to 4.0 | `CC-BY-ND-4.0` etc. | As CC BY, and always played whole and unedited. |
| A site's own licence | `SITE:<name>` | Only if it explicitly allows internet radio, streaming or broadcast. |

Not accepted: anything "personal use only", "YouTube/video only" wording that doesn't cover
streaming, anything without a clear licence, and anything ripped from YouTube or Spotify. Music under
any non-commercial (NC) licence is never accepted.

## Spoken word

For Story Time, spoken word may also use
[CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/) (`CC-BY-NC-ND-4.0`), while the
station stays non-commercial and plays each item whole and unedited, with credit.

- **LibriVox:** public domain (`PD`).
- **Escape Pod, PodCastle, Pseudopod, Cast of Wonders:** CC BY-NC-ND, checked on each episode's
  own page. Older episodes were released under 3.0, which I don't accept yet, and Pseudopod's
  about page states no licence at all.
- **Internet Archive:** only items whose own page marks them public domain or CC0. Many uploads
  aren't.
- **Commercial audiobooks** (Audible and the like) are never aired, bought or not.
- **Fan fiction and indie authors** only with the author's written permission, stored as evidence.
