# Security Policy

## Reporting a vulnerability

If you find a security problem in ABM Radio, report it privately rather than in a public
issue.

**Email:** [admin@audiobookmanager.com](mailto:admin@audiobookmanager.com)

You can also use GitHub's
[private vulnerability reporting](https://github.com/sunbrolynk/abm-radio/security/advisories/new).

I'll acknowledge the report as soon as I can and work on a fix with you before anything is
disclosed publicly.
